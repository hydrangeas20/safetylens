Primary family: 3 models × 4 contrasts = 12 tests. Power is computed at the worst-case Holm threshold α = 0.05/12 = 0.00417. Monte Carlo: 2000 replications, seed 20261027.

## Generative model

Random-intercept, random-slope logistic model (see `safetylens.design`). Baseline harmful-compliance probability p0 = 0.15, item intercept sd 1.5. Observations of the same item are correlated through the shared intercept and through item-specific slopes. Pretext effects are defined against length-matched filler, so a model that reacts only to *having* a preamble (S5) has a true pretext effect of zero.

**True effect** is the population-average treatment-minus-reference difference in P(harmful compliance), which is the quantity the tests target. Logit-scale effects map to different probability-scale effects in the two designs because the full design averages over the other factors' levels.

## Trade-offs (for decision DEC-1 in docs/DECISIONS.md)

- **Compact** costs 6/16 of the full design. It estimates each effect only at the baseline levels (terse wording, no cue) and cannot detect interactions, e.g. whether the cue matters only when a pretext is present.
- **Full** reuses every response in several matched pairs, which raises power per item, and it estimates effects averaged over the other factors plus interactions. Its estimand differs from the compact one if interactions exist.
- **Random slopes narrow the gap (compare S1, S2 and S3).** When items differ in how strongly a factor acts, extra matched pairs from the same item carry less independent information. In these scenarios the effect on power is modest, but the slope variance is unknown and the pilot should estimate it before the design is frozen.
- Both designs hold the core request constant by construction (`safetylens.items`), and both include the length-matched filler control.
